# IST Pro Skill（個人専用・高速・本格仕様）

あなた専用のIST生成Skill。前提確認・設計ルール説明・実行手順説明をすべてスキップし、
素材投入から高品質な原稿・スライドまでを最短で完成させる。

## 呼び出し方

```
/ist-pro
```

素材（テキスト・URL）を貼り付けながら呼び出す。
または呼び出し後に素材を投入する。

## 前提（確認不要・常に適用）

### 読者設定（固定）

- 職種：税理士・司法書士（開業3〜10年、規模10名程度）
- 抽象度：実務用語は前提知識。経営戦略用語は初出時のみ補足。
- 警戒感：「きれいごと」に慣れている。数字・構造・事例で自分ごと化させる。
- 時間：流し読みでも骨格がわかる構造必須。

### スライド設計ルール（固定）

- 1枚1メッセージ
- 見出し＝結論（問いかけNG）
- 本文3行以内→図・表・箇条書きで補完
- 略語は初出時に()補足
- 各枚末尾に▶で始まる示唆を入れる
- 読者より一段上の抽象度で整理。ただし置いてけぼりにしない

### 固定ページ構成（変更不可）

- P1：表紙
- P2：はじめに（必須・以下の3要素を含む）
  - ① 本資料の作成意図（なぜこの資料を作ったか）
  - ② 対象読者が抱えている課題・相談頻度の高い項目への言及
  - ③ 業界動向の要約（1〜3行）と本資料で得られること
- P3：目次（章タイトル＋対応ページ番号を記載）
- P4以降：本編

### カラーパレット（固定）

```
ACCENT  = '#1A3A5C'
ACCENT2 = '#2E7D9E'
LIGHT   = '#E8F4F8'
TEXT    = '#1A1A1A'
MUTED   = '#555555'
```

## 実行フロー

### STEP 1｜素材解析（自動）

素材を受け取ったら即座に以下を実行し、結果を提示する。確認を求めない。

1. 使える情報の抽出（統計・スキーム・事例・名言レベルの示唆）
2. 不足情報の特定（穴のリストアップ）
3. ストーリーライン候補を3パターン生成

### STEP 2｜ストーリーライン選択（3パターン提示）

素材の性質に応じて以下から最適なパターンを自動判定して提示。
選択または「このまま進める」で即座に次へ。

#### パターンA：問題提起型

```
P1：表紙
P2：はじめに
P3：目次
Ch1（P4〜）：現状の問題（業界・市場）
Ch2：読者自身が直面している課題
Ch3：放置するとどうなるか（数字）
Ch4：解決策の設計
Ch5：実行プロセス
Ch6：次の壁
Ch7：哲学的結論
裏表紙：CTA
```

向いているテーマ：競合に負けている・案件が来ない・依存構造からの脱却

#### パターンB：機会提示型

```
P1：表紙
P2：はじめに
P3：目次
Ch1（P4〜）：市場の変化（確定した未来）
Ch2：その変化が生む空白地帯
Ch3：先行事例・数字的優位性
Ch4：具体的スキーム
Ch5：営業・運用設計
Ch6：スケールへの壁
Ch7：結論
裏表紙：CTA
```

向いているテーマ：新規マーケット開拓・提携戦略・新サービス立上げ

#### パターンC：フレームワーク提示型

```
P1：表紙
P2：はじめに
P3：目次
Ch1（P4〜）：全体像の俯瞰（地図を渡す）
Ch2：各要素の詳細設計
Ch3：実装の優先順位
Ch4：判断基準の提示
Ch5：よくある失敗と回避策
Ch6：応用・発展
Ch7：結論
裏表紙：CTA
```

向いているテーマ：業務設計・仕組み構築・体系的な知識移転

### STEP 3｜1枚ごとのビジュアル設計（詳細指定モード）

各スライドを生成する際、以下の要素を1枚ずつ設計して提示する。
確認が必要な場合のみ「要確認」フラグを立てる。それ以外は自動判断で進む。

**1枚の設計要素：**

- タイトル：（結論形・15文字以内）
- レイアウト：箇条書き / 比較表 / フロー図 / ボックス分割 / 数値ハイライト
- メインビジュアル：（図解の構造を言語で定義）
- ▶示唆：（1文・行動または認識の変化を促す）
- 要確認フラグ：あり / なし

**レイアウト自動判定ルール：**

| 内容の性質 | 自動選択レイアウト |
|---|---|
| 3要素以下の対比 | ボックス分割 |
| 4要素以上の比較 | 比較表 |
| 時系列・プロセス | フロー図 |
| 単一の強いメッセージ | 数値ハイライト |
| 複数の独立した要点 | 箇条書き |

### STEP 4｜品質チェック（自動・全枚数）

原稿完成後、以下を全枚数に対して自動チェックし、問題箇所だけ報告する。

**自動チェック項目：**

- □ 1枚1メッセージ：見出しが1文で言えるか
- □ 結論ファースト：見出しが答えになっているか（問いかけになっていないか）
- □ 読者の言葉：読者が使わない言葉が混入していないか
- □ 数字の根拠：統計・比較数値に出典があるか
- □ 行動導線：読了後の「次の一手」が明確か
- □ 抽象と具体：概念→図解→「つまりあなたの事務所では」で着地しているか
- □ 禁止表現：スタッフの主体性を損なう表現がないか
- □ 法的リスク：非弁・非税理士行為に抵触する記述がないか

**報告フォーマット：**

```
✅ 全枚数クリア：（クリアした項目）
⚠️ 要修正（N箇所）：
  - スライドX：（問題内容）→（修正案）
```

修正案を提示した上で「このまま修正する / 確認してから修正」を選ばせる。

### STEP 5｜ISTシリーズ管理（一貫性チェック）

2本目以降のISTを作る場合、以下を自動で参照・適用する。

**参照する過去ISTの情報：**

1. 使用済みの数値・統計（重複排除）
2. 確立した概念・フレームワーク（用語統一）
3. 読者への語りかけトーン（一貫性維持）
4. 過去CTAとの重複チェック（同じ「次の一手」を繰り返さない）

**シリーズとして成立させるために、以下を各ISTに付与する：**

- ISTシリーズタグ：（例：相続マーケット獲得シリーズ vol.2）
- 前提知識リンク：（例：vol.1を読んでいる前提で説明を省略する箇所）
- 発展先リンク：（例：次号では○○を扱う予定）

### STEP 6｜Apps Script生成（高速）

実行手順の説明はスキップ。コードのみ出力する。

**安全設計（自動適用・確認不要）：**

```javascript
// 空文字ガード
function safeStr(v) {
  if (v === null || v === undefined || v === '') return ' ';
  return String(v);
}
// var統一・HEXのみ・Logger.log()のみ使用
```

## プロ版専用オプション

呼び出し時に以下のオプションを付けて動作を変更できる。

| コマンド | 動作 |
|---|---|
| `/ist-pro fast` | レビュー確認なしで全自動生成 |
| `/ist-pro review` | 各Chapterで必ず確認を挟む（丁寧モード） |
| `/ist-pro visual` | ビジュアル設計を詳細に指定してから原稿生成 |
| `/ist-pro series` | シリーズ管理モード（過去ISTとの一貫性を重視） |
| `/ist-pro slide-only` | 原稿テキストを貼り付けてスライド生成だけ行う |

## 蓄積されるナレッジ

ISTを作るたびに以下を内部で更新する（セッション内で有効）：

1. 使用した数値・出典のリスト
2. 読者に刺さった表現パターン
3. 採用したストーリーラインパターンとその理由
4. 廃棄した構成案とその理由
5. レビューで修正が入った箇所のパターン

次のISTを作る際、これらを参照して初期精度を上げる。

## スタンダード版との違い

| 項目 | スタンダード版 | プロ版 |
|---|---|---|
| 前提確認 | 毎回確認 | スキップ（固定） |
| 設計ルール説明 | 毎回説明 | スキップ（自動適用） |
| ストーリーライン | 1パターン提示 | 3パターン比較 |
| ビジュアル設計 | 原稿レベル | 1枚ごとに詳細設計 |
| 品質チェック | 手動チェックリスト | 全自動・問題箇所のみ報告 |
| シリーズ管理 | なし | 過去ISTとの一貫性チェック |
| 実行手順説明 | あり | なし |
| レビュー | 3分割で確認 | オプション選択 |
| P2はじめに | なし | 自動生成（必須） |
| P3目次 | なし | 自動生成・ページ番号付き（必須） |
